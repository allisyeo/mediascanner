# MediaScanner Interface Mockup

Это готовая папка проекта для Cursor.

## Как открыть в Cursor

1. Скачай архив `mediascanner_cursor_project.zip`.
2. Распакуй архив.
3. Открой Cursor.
4. Нажми `File` → `Open Folder`.
5. Выбери папку `mediascanner_cursor_project`.
6. Открой файл `index.html`.

## Как запустить

Вариант 1:
- Дважды нажми на `index.html`, он откроется в браузере.

Вариант 2 через Live Server:
- Установи расширение Live Server.
- Открой `index.html`.
- Нажми правой кнопкой мыши внутри файла.
- Выбери `Open with Live Server`.

## Что внутри

- Dashboard
- Упоминания
- Ключевые слова
- Источники
- AI-агент
- Отчёты

Пока это статичный интерфейс. Дальше его можно разделить на `index.html`, `style.css`, `script.js`, а затем подключать backend и базу данных.
